# assets

The project's logos.
Each set has a full logo and a mark, each in light and dark, and a favicon.

In this project the GitHub READMEs show them: the repository's logo at the top of the [repository README](../README.md), and the project and package marks in its tables and in the [packages README](../packages/README.md).
The docs site and the package sites keep their own copies, under `docs/assets/` and `packages/<name>/docs/assets/`.

## Where to look

- `logo.svg`, `logo-dark.svg`, `logo-mark.svg`, `logo-mark-dark.svg` and `favicon.svg`: the repository's logo.
- `logos/<name>/`: one set per package (`nowcastutils` to `bdbvhub`), per project (`fine-tuned-foundation`, `joint-model-informed-renewal`, `hub-submission`), for the workflow (`nowcastworkflow`) and for the repository (`bdbv-hub-modelling`).
- `logos/contact-sheet.png`: every logo on one sheet.
